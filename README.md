# market-data

一个全球「质量 × 价值」股票筛选器。每个交易日新加坡时间 05:30 由 GitHub Actions 自动运行。

**股票池**（只用公开标准）：标普500、纳斯达克100、沪深300、港股主要公司（`config/hk_major.csv`）、市值前列的加密货币，约 1,000 只。

**筛选规则**（`scripts/run.py` 的 `RULES`）
- 质量门槛：ROE ≥15%、自由现金流为正、负债/权益 ≤100%、营业利润率 ≥10%（金融/地产只看 ROE）
- 便宜（其一）：FCF 收益率 ≥5%、预期 PE ≤15、价格处于 5 年区间最低 20%、金融/地产 PB ≤1.2
- 错杀：20 日跌 ≥15% 或距 52 周高回撤 ≥35%，且盈利预期未恶化
- 金融/地产不算 FCF；非金融 FCF 收益率 >25% 标为数据存疑；周期行业单独标注；名单每行业最多 2 个

**输出**：`data/latest/`（`prices.json` 全池最新价与汇率、`screen.json` 候选名单、`report.md` 可读报告、`metrics.csv` 全池指标），按日归档到 `data/history/`。

数据来自雅虎财经免费接口，港股/A股基本面有缺口。仅供研究，不构成投资建议。
